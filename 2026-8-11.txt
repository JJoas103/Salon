## 요구사항
- 마이페이지에서 내가 커뮤니티에 쓴 글/댓글을 확인할 수 있는 탭 필요
- 누가 내 글에 댓글을 달았는지도 마이페이지에서 확인 가능하게
- 마이페이지 기존 틀(사이드바 + 프레임)은 유지

## 설계
- 이 프로젝트 마이페이지는 허브 앤 스포크 구조(mypage.jsp는 통계+메뉴만, 실제 "탭"은
  쿠폰함/적립금/작성한 리뷰처럼 각각 독립 라우트인 스포크 페이지) -> 동일 컨벤션으로
  신규 스포크 페이지 /common/my-community 추가
- 페이지 내부 "내가 쓴 글/내가 쓴 댓글/내 글에 달린 댓글" 3분류는 커뮤니티 목록의
  카테고리 탭(.cat-tab, 쿼리파라미터 ?tab= 전환) 패턴 재사용

## 백엔드 변경
- PostMapper.java/xml: findByUserId(userId) 추가 (내가 쓴 글, 페이지네이션 없이 전체 조회)
- CommentMapper.java/xml
  - findByUserId(userId) 추가 (내가 쓴 댓글, Posts JOIN해서 post_title 채움)
  - findRepliesToUserPosts(userId) 추가 (내 글에 달린 남의 댓글, 본인이 자기 글에 단 댓글은 제외)
  - countRepliesToUserPosts(userId) 추가 (마이페이지 뱃지 숫자 전용 COUNT)
- PostService.java/PostServiceImpl.java: getMyPosts, getMyComments, getRepliesToMyPosts,
  countRepliesToMyPosts 추가 (댓글 관련 로직은 원래도 PostService에 있어서 그대로 이어서 구현,

- CommonController.java
  - PostService 의존성 추가
  - mypage()에 communityReplyCount(받은 댓글 수) 모델 속성 추가
  - GET /common/my-community?tab=posts|comments|replies 핸들러 추가

## 프론트엔드 변경

- 신규 common/my-community.jsp: 마이페이지 프레임 유지, 서브탭 3개(글/댓글/받은 댓글),

[3. 게시글 삭제돼도 댓글 기록은 로그로 보존 + 죽은 기록 수동 삭제(X)] 진행상황

## 요구사항
- 지금은 게시글을 삭제하면 "내가 쓴 댓글"/"내 글에 달린 댓글" 기록까지 같이 사라짐
- 그러지 말고 로그처럼: 게시글이 삭제됐으면 회색으로 "삭제된 게시글입니다" 표시하고
  내가 무슨 댓글을 썼는지 내용은 남아있게
- 옆에 X 표시로 그 기록을 삭제하고 싶으면 삭제할 수 있게
- (대화로 확정) X는 게시글이 이미 삭제된(회색) 항목에만 뜨고, 누르면 DB에서 실제 영구 삭제

## 설계
- 댓글이 살아남으려면 Posts 행 자체가 사라지면 안 됨 -> 기존 "블라인드"(status='blinded')
  패턴을 그대로 확장해서 글 삭제도 하드 삭제 대신 소프트 삭제(status='deleted')로 전환
- 기존 목록/검색/상세/"내가 쓴 글" 탭은 전부 이미 status='visible' 필터가 있어서
  소프트 삭제된 글은 자동으로 안 보임 (추가 수정 불필요)
- "내가 쓴 댓글"/"내 글에 달린 댓글" 쿼리에서만 status='visible' 필터를 빼고,
  댓글에 연결된 게시글 상태(post_status)를 같이 조회해서 화면에서 분기

## DB 변경 (로컬 salu DB에 실제 적용 완료)
- sql/schema.sql: Posts.status ENUM에 'deleted' 추가 ('visible','blinded','deleted')
- 신규 sql/migration_comment_log.sql: ALTER TABLE Posts MODIFY COLUMN status ENUM(...)

## 백엔드 변경
- PostMapper.java/xml: softDelete(postId) 추가 (UPDATE Posts SET status='deleted')
- PostServiceImpl.deletePostCascade() 수정
  - commentMapper.deleteByPostId(...) 호출 제거 (댓글은 이제 안 지움)
  - postMapper.delete(...) (하드 삭제) -> postMapper.softDelete(...)로 교체
  - postReportMapper/postLikeMapper의 deleteByPostId, fileService.deleteFile은 그대로 유지
- CommentVO.java: postStatus 필드 추가 (Posts JOIN 조회 전용, DB 컬럼 아님)
- CommentMapper.xml
  - findByUserId, findRepliesToUserPosts: AND p.status='visible' 필터 제거,
    SELECT에 p.status AS post_status 추가, resultMap에 post_status -> postStatus 매핑 추가
  - countRepliesToUserPosts(마이페이지 뱃지)는 그대로 둠 (여전히 visible 글 기준으로만 카운트)
- PostService.java/PostServiceImpl.java: removeCommentAsPostOwner(commentId, userId) 신규 추가
  - 내 글에 달린 남의 댓글을 지우는 새 권한 경로 (기존 removeComment는 댓글 작성자만 허용)
  - 게시글 주인 본인 확인 + 게시글 status가 'visible'이 아닐 때만 허용(서버에서도 X버튼 규칙 강제)
- CommonController.java: 신규 엔드포인트 2개
  - POST /common/my-community/comments/{commentId}/delete (내가 쓴 댓글용, removeComment 재사용)
  - POST /common/my-community/replies/{commentId}/delete (내 글에 달린 댓글용, removeCommentAsPostOwner)

## 프론트엔드 변경
- common/my-community.jsp: 댓글/받은 댓글 탭 카드를 postStatus 기준으로 분기
  - visible: 기존처럼 클릭 가능한 카드(제목+링크), X 없음
  - 그 외(blinded/deleted): 회색 카드, 제목 대신 "삭제된 게시글입니다", 댓글 내용은 그대로 표시,
    우측에 X 삭제 폼(common/community/detail.jsp의 댓글삭제 폼 패턴 재사용)
- resources/css/user.css: .comment-activity-card.is-dead(회색 스타일), .comment-activity-meta를
  flex row로 변경해서 날짜와 X버튼 한 줄 배치
