# Spring 프로젝트 초기 세팅 가이드

> 레거시 **Spring Framework 5 (XML 설정)** + MyBatis + JSP + MySQL + Spring Security 기반
> 이 프로젝트(`spring-board`)와 동일한 구조로 새 프로젝트를 세팅하는 순서를 정리한 문서입니다.

---

|------|------|
| **프론트엔드** | JSP, JSTL, HTML/CSS, JavaScript, Spring Security Taglib |

## 1. Maven 프로젝트 생성 + `pom.xml`

프로젝트의 뼈대. 두 가지가 핵심입니다.

### ① packaging을 war로
JSP를 쓰는 웹앱이므로 `jar`가 아니라 `war`:
```xml
<packaging>war</packaging>
```

### ② 버전을 properties로 관리
```xml
<properties>
    <maven.compiler.source>17</maven.compiler.source>
    <maven.compiler.target>17</maven.compiler.target>
    <spring.version>5.3.39</spring.version>
    <spring-security.version>5.8.13</spring-security.version>
</properties>
```

### ③ 핵심 의존성 (처음엔 이 정도만)
| 의존성 | 역할 |
|--------|------|
| `spring-webmvc` | Spring MVC 본체 |
| `javax.servlet-api` (provided) | 서블릿 API (톰캣이 제공하므로 provided) |
| `jstl` | JSP 태그 (`<c:forEach>` 등) |
| `mysql-connector-java` | MySQL 드라이버 |
| `mybatis` + `mybatis-spring` | SQL 매핑 |
| `spring-jdbc` | DataSource / 트랜잭션 |
| `spring-security-web` / `-config` | 로그인·권한 |

> elasticsearch, websocket, oauth 등 부가기능은 **나중에** 추가하고, 처음엔 위 핵심만으로 시작하세요.

## 2. 폴더 구조

Maven 웹 프로젝트 표준 구조:

```
src/main/
├── java/com/soldesk/              ← 자바 코드
│   ├── controller/                ← 요청 처리 (@Controller)
│   ├── service/                   ← 비즈니스 로직 (@Service)
│   ├── mapper/                    ← DB 접근 인터페이스 (MyBatis)
│   ├── vo/                        ← 데이터 객체 (BoardVO 등)
│   └── config/                    ← 자바 기반 설정
├── resources/                     ← classpath 리소스
│   ├── applicationContext.xml     ← 루트 설정 (DB/트랜잭션)
│   ├── mapper/*.xml               ← 실제 SQL 쿼리
│   └── properties/*.properties    ← DB 접속정보 등
└── webapp/WEB-INF/
    ├── web.xml                    ← 웹앱 진입점 설정
    ├── spring/dispatcher-servlet.xml ← MVC 설정
    └── views/*.jsp                ← 화면
```

> 계층 흐름: **Controller → Service → Mapper → DB**

## 3. `web.xml` — 웹앱의 관문

톰캣이 앱 시작 시 **가장 먼저 읽는 파일**. 4가지를 등록합니다.

### ① ContextLoaderListener (루트 설정 로딩)
```xml
<listener>
    <listener-class>org.springframework.web.context.ContextLoaderListener</listener-class>
</listener>
<context-param>
    <param-name>contextConfigLocation</param-name>
    <param-value>classpath:applicationContext.xml</param-value>
</context-param>
```

### ② DispatcherServlet (모든 요청의 심장)
```xml
<servlet>
    <servlet-name>dispatcher</servlet-name>
    <servlet-class>org.springframework.web.servlet.DispatcherServlet</servlet-class>
    <init-param>
        <param-name>contextConfigLocation</param-name>
        <param-value>/WEB-INF/spring/dispatcher-servlet.xml</param-value>
    </init-param>
    <load-on-startup>1</load-on-startup>
</servlet>
<servlet-mapping>
    <servlet-name>dispatcher</servlet-name>
    <url-pattern>/</url-pattern>
</servlet-mapping>
```

### ③ 한글 인코딩 필터 (UTF-8 강제)
```xml
<filter>
    <filter-name>encodingFilter</filter-name>
    <filter-class>org.springframework.web.filter.CharacterEncodingFilter</filter-class>
    <init-param><param-name>encoding</param-name><param-value>UTF-8</param-value></init-param>
    <init-param><param-name>forceEncoding</param-name><param-value>true</param-value></init-param>
</filter>
```

### ④ Spring Security 필터
```xml
<filter>
    <filter-name>springSecurityFilterChain</filter-name>
    <filter-class>org.springframework.web.filter.DelegatingFilterProxy</filter-class>
</filter>
```

> **핵심 개념** — 루트 컨텍스트(`applicationContext.xml`: DB·서비스·보안)와 서블릿 컨텍스트(`dispatcher-servlet.xml`: 컨트롤러·뷰)를 **분리**합니다.

## 4. `applicationContext.xml` — 루트 설정 (DB & 트랜잭션)

DB 관련 4대 빈을 등록합니다.

1. **DataSource** — DB 연결 정보 (`${db.url}` 등을 properties에서 주입)
2. **SqlSessionFactory** — MyBatis 핵심, mapper XML 파싱
   ```xml
   <property name="mapperLocations" value="classpath:mapper/*.xml" />
   ```
3. **MapperScannerConfigurer** — `com.soldesk.mapper` 인터페이스를 자동 구현
4. **transactionManager** + `<tx:annotation-driven>` — `@Transactional` 활성화

---

## 5. `db.properties` — 접속정보 분리

민감정보를 XML에 직접 박지 않고 별도 파일로 분리:
```properties
db.driver=com.mysql.cj.jdbc.Driver
db.url=jdbc:mysql://localhost:3306/스키마명
db.username=사용자
db.password=비밀번호
```

> 💡 실무에서는 이 파일을 `.gitignore`에 넣어 **커밋하지 않습니다** (비밀번호 노출 방지).

---

## 6. `dispatcher-servlet.xml` — MVC 설정

화면·컨트롤러 관련 설정.

- `<mvc:annotation-driven />` → `@Controller`, `@RequestMapping` 활성화
- `<context:component-scan>` → controller·service 패키지 스캔
- **ViewResolver** → `"home"` 반환 시 → `/WEB-INF/views/home.jsp`
  ```xml
  <bean class="org.springframework.web.servlet.view.InternalResourceViewResolver">
      <property name="prefix" value="/WEB-INF/views/" />
      <property name="suffix" value=".jsp"/>
  </bean>
  ```
- `<mvc:resources>` → CSS/이미지 등 정적파일 경로

## 7. 첫 동작 확인 (Hello World)

세팅 검증용 최소 코드.

**Controller:**
```java
@Controller
public class HomeController {
    @GetMapping("/")
    public String home() {
        return "home";   // → /WEB-INF/views/home.jsp
    }
}
```

**JSP:** `views/home.jsp` 생성 → Tomcat 실행 → `localhost:8080` 접속 → 화면이 뜨면 **기본 골격 완성**.

이후 **DB 연동(mapper) → 시큐리티 → 게시판 CRUD** 순으로 살을 붙입니다.
